To be a developer is to know. To know in detail how a system operates. To know all the moving parts that makes the thing go. It is to live with the system in your mind. To run the code in your head and know exactly where it will break. This is intimate technical knowledge. It is not documentation. It is not diagrams. It is the living understanding of a system that only comes from years of working with it.
